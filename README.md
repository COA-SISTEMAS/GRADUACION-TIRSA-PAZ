- **Hora:** 6:30 p. m.
- **Lugar:** Restaurante La Cumbre
- **Menú:** Fettuccine Alfredo, Pollo Astori y filete de cerdo con salsa de tamarindo.

## Publicar en GitHub Pages

1. En el repositorio, abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **GitHub Actions** como fuente.
3. Abre **Actions** y verifica el flujo **Publish graduation invitation**. Si no se ejecuta automáticamente, selecciona **Run workflow**.
4. Cuando termine correctamente, abre la dirección que aparece en **Settings → Pages**.

La invitación está diseñada para dispositivos móviles y computadoras. No usa bases de datos ni recopila información de visitantes.
